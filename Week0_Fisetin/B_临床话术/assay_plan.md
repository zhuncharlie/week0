# 验法(assay_plan.md)—— 给合作医生 / 湿实验的具体操作说明

## 候选:Venetoclax(ChEMBL:CHEMBL3137309,已上市,2016 年批准,BCL-2 选择性抑制剂)

## 为什么是它(一句话)
它和 Fisetin 共享同一条"假说通路"(SCAPs/BCL-2 家族),是**真正已上市**的药(不像 Navitoclax
只到临床三期),而且因为只打 BCL-2、不打 BCL-xL,理论上应该比 Navitoclax 更不容易引起血小板毒性——
但据我们这次查询范围内所见,它没有被直接测过对衰老细胞的清除效果。

## 怎么验(照搬本论文 Fig.1C + Fig.4E 的设计,换成 Venetoclax)

| 步骤 | 做法 | 对标论文哪张图 |
|---|---|---|
| 1. 细胞模型 | 人源 IMR-90 成纤维细胞,20μM 依托泊苷处理 24h 诱导衰老,2 天后 ~70% 细胞 SA-β-gal+ | Fig.1C 方法 |
| 2. 给药 | Venetoclax 剂量梯度(建议 0.1–10μM,参考其已知细胞内有效浓度),处理 48h | Fig.1C 剂量范围 |
| 3. 读数① | C12FDG 染色测 SA-β-gal+ 细胞比例(用 IN Cell Analyzer 或类似高内涵成像) vs 总细胞数(Hoechst) | Fig.1A-C |
| 4. 读数② | 跟 Fisetin(1–15μM,同一批细胞平行对照)头对头比较"红条塌多少、黑条站不站得住" | Fig.1A 的红黑条逻辑 |
| 5. 若步骤2-4阳性 → 人组织验证 | 人脂肪外植块,20μM Venetoclax,48h,测 SA-β-gal+ 比例 + SASP 因子(IL-6/IL-8/MCP-1) | Fig.4E-F |
| 6. 安全性旁证 | 不需要新做动物实验——Venetoclax 已有上市后的人体安全数据(血液毒性为主,非血小板特异性),直接引用说明书 | — |

## 看什么指标判断"验成了"
- SA-β-gal+ 细胞比例显著下降,且**总细胞数(黑条)基本不掉**——这是区分"senolytic"和"化疗药"的
  关键门道(§6 坑①同款逻辑)。
- 浓度量级应该落在个位数 μM,跟 Fisetin 1–15μM 一个数量级,太高浓度才起效的候选没有实用价值。

## 如果验出来是阴性,说明什么
说明"同打 BCL-2 家族"这个假说不足以预测 senolytic 活性——衰老细胞对凋亡的抗性可能更依赖
BCL-xL 而不是 BCL-2(这也是为什么 Navitoclax/A1331852 在既往文献里比单纯 BCL-2 抑制剂更常被
报道为 senolytic)。这本身就是一个值得写进下一轮报告的阴性结果。
